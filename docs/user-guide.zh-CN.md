# Cash Rec 0.2.0 使用说明

本版在本地处理 TMA/TMG，生成每日四表及月度 TMA、TMG、Total、Break down。Total 只合计 TMA/TMG。生成完成后，仍需在 Excel 填写人工区域并核对 Check。

## 安装与启动

运行 `CashRec_Setup.exe`，从桌面或开始菜单启动 Cash Rec。安装包包含运行依赖，不需要 Python、.NET SDK 或开发工具。安装包不含项目源码。

程序安装目录与业务工作区分开。升级或卸载程序不会删除独立的业务工作区。覆盖重要结果前请另存备份。

实测系统为 Windows 11 Enterprise 26100 x64；安装器最低要求 Windows 10 19041 x64。尚未完成 Windows 10 或干净虚拟机兼容矩阵。安装包未代码签名。

## 准备文件

日期目录采用 `YYYY.MM.DD`，例如 `2026.10.25`。目录可直接位于工作区，也可位于 `data/risk_and_cash_to_process` 下。每个日期分别准备自己的文件，不借用后来更新的累计快照。

在各日期目录的 `Needed files` 内放置：

| 子目录 | 文件名 |
| --- | --- |
| Bank | NAB AU.csv |
| Bank | NAB GL.csv |
| MT4/MT4 | Transaction Summary Report.csv |
| MT4/Risk | Accounting Equity Report.csv |
| PSP+BANK | BANK BD.xlsx |
| PSP+BANK | PSP Balance Summary.xlsx |
| Rate | VFSC Rate.xlsx |

将完整的 `account_mapping.xlsx` 放入工作区 `config` 或 `db/tmc`。单日文件和映射也可通过界面导入。缺项草稿不能替代完整映射；不要猜测银行分类。

交易与权益报告按监管字段中的 ASIC/VFSC 关键词识别 TMA/TMG。NAB AU 属于 TMA，NAB GL 属于 TMG；PSP A 列的 PSPAU 属于 TMA，PSPGL 属于 TMG。映射同键只匹配一次，不因金额相同删除真实交易。

CSV 使用准备文件内的全部日期，不再按目录日截断。PSP 只取当前目录日对应的 Amount；真空白按数值 0。汇率按业务日期匹配，USDT 固定为 1。非法文本和没有有效数值缓存的金额公式需修正后重跑。

## 生成结果

选择业务工作区和日期，先检查文件，再生成报表。默认处理单日；勾选“日期范围”后选择结束日期，含首尾并按日期升序处理。结束日早于开始日时需修正后再运行。范围模式下将文件分别放入各日期目录，单日导入请切回单日模式。

每日结果位于各日期目录的 `CashRec_Base.xlsx`，包含 Equity、Bank、PSP、TransactionExchange。月度结果位于日期目录上一级的 `monthly/CashRec_Breakdown_YYYY.MM.xlsx`。

界面列出结果位置和诊断。文件检查通过仅表示输入齐备；生成失败或结果不完整时，按诊断中的文件、工作表、日期和行号修正。非零 Check 不阻止自动生成完成，也不表示人工核对通过。

范围结果按日列出成功、缺项、失败或部分完成，并保留每天的结果和诊断路径。缺目录、源文件或 PSP 日期列的日期会明确列出，其他可用日期继续处理；仍然缺少有效同口径上期的日期不会标为成功。范围内的周末不会自动跳过。

重复运行相同范围会更新已有日期。跨月时每月只初始化一次，后续日期继续追加。范围结束后，“打开结果位置”进入日期目录的共同上级，所有已生成的每日和月度文件仍可访问。

## 上期与在途

保留此前日期目录。程序使用此前最近的有效同口径余额；有必要时从该日 Equity、NAB AU/GL、PSP 和汇率原文件重算。重算余额不要求此前交易文件。

缺有效上期时，相应 Previous、Movement、PNL 或月度 DIFF 留空并明确提示。不要将空白当作正常零差额。

月度 PSP Pending 还需要当前及上期各自目录内的 BANK BD 快照。使用 Q 列实体对应的 T 列 PSP On The Way，并核对 R−S。历史日期不能借用后来更新的快照。

## Excel 人工填写

首次 DEP 为数值 0。修改后，PNL 按 `Movement−DEP` 联动。Movement 由当前与上期余额计算。

Break down 的 To LP、Bank Fee、Bank fee-conversion、Time Diff 首次真正空白，保留默认格式供人工填写。Error 保留空数据。Check 沿用 `F−G−H−I−J−K−L−M−N`，没有新增舍入、容差或自动归零。

H/I 读取同日 TMA/TMG 的 SETTLE PNL，J 固定为数值 0；K 汇总 `PSP CN Commission` 和 `PSP Commission` 的带符号 USD Equivalent，规范空格与大小写，每条计一次，不额外限制 Source。TMA/TMG/Total 删除原 I/K/M 后按业务字段重绑，Break down 同字母列保留。

在 Excel 保存人工修改后，关闭输出文件再重跑。新日期的人工区域按默认初始化；已有日期更新自动值，保留可匹配的空白、0、负数和格式。

## 重跑与备份

同日重跑更新已有日期，不重复追加。DEP 按业务日期、实体、IB/Standard 和币种匹配；月度人工值按工作表和日期匹配，不按旧行号搬移。

消失或无法匹配的人工值保存在日期目录的 `UnmatchedManual_*.csv`，诊断提供路径，需人工核对。替换前的完整原文件备份位于每日及月度 `backups` 目录。

程序先准备每日四表、月度四表及未匹配清单，再提交替换。失败时不将部分输出标为成功；诊断说明旧结果或恢复文件的位置。不要把旧文件仍存在当作本次任务成功。

报表已生成但诊断记录无法保存时，界面仍显示已生成文件位置，并提示记录未保存。范围会保留这些日期的部分完成状态及后续日期结果。修正提示中的写入问题后再重跑，不能将缺少诊断文件理解为没有生成报表。

## 月中与跨月

月中按日期追加，同日更新。进入新月时，只在新月文件中保留上月四表一致的最后有效日期行，再追加新数据；上月文件不改写。合计、说明和仅格式尾行不作为基准。

上月基准人工值随行保留。缺上月文件、四表末日不一致或基准分类过旧时，先通过界面生成或重算对应历史日期。作为跨月来源的文件也需关闭。

首次月中运行可以使用同月有效余额启动。月初无上期会明确不完整；后续同月数据不会自动认证缺失的跨月基准。补齐上月后重跑，会补入基准并保留新月已有日期和人工值。

旧分类日期会显示 Mixed 提示。按各日期自己的输入重跑；系统只将已重算日期标记为新规则。当前规则按 BANK BD Comment 关键词分类，不再要求 Rational 包含 `tf`，既有费用与 PSP 冲突优先级保留。
